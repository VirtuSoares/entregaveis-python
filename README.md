## 📁 Estrutura de Entregáveis

- 📂 **[Listas-Tuplas-Conjuntos](./Listas-Tuplas-Conjuntos)** (Sprint 04)
  - **Descrição:** Sistema de gerenciamento de produtos.
  - **Recursos aplicados:**
    - Cadastro e manipulação com **Listas** (`append()`).
    - Ordenação crescente (`sort()`) e decrescente (`sorted(..., reverse=True)`).
    - Remoção de duplicatas de categorias usando **Conjuntos** (`set()`).
    - Agrupamento de estatísticas (mínimo, máximo e média) usando **Tuplas** imutáveis.
    - Relatório final formatado dinamicamente com **f-strings**.
